# Maze Lab — веб-прототип

Рабочий цикл: **сгенерировать → изменить в редакторе → пройти → сохранить → загрузить**. Текущий объём и чек-лист: [WEB-PROTOTYPE.md](docs/reboot/WEB-PROTOTYPE.md).

## Попробовать

После сборки запустите `./start-web.command` (на macOS можно открыть двойным щелчком), затем откройте [веб-прототип](http://127.0.0.1:1421).

1. Нажмите **Создать лабиринт**, выберите 12 или 30 комнат и нажмите **Сгенерировать**. Seed позволяет повторить ту же карту.
2. Откройте результат в редакторе. Выбирайте комнаты на плане, меняйте числовые параметры или перемещайте мышью. **Отменить** восстанавливает предыдущее изменение. Ошибки остаются в черновике; прохождение доступно после проверки актуальной карты.
3. **Пройти** сохраняет проверенную карту в библиотеке. Подготовьте попытку и нажмите **Начать**. WASD — движение, стрелки влево/вправо — поворот, мышь — осмотр. **Пауза → Завершить попытку → Остановить и сохранить** сохраняет прерванное прохождение. Достижение выхода завершает попытку автоматически.
4. Библиотека и вкладка **Прохождения** сохраняются после перезагрузки страницы. **Редактировать** повторно открывает карту; **Результат** — сохранённую попытку. Просмотренные карты показывают своё название.
5. **Экспорт карты / Экспорт попытки** скачивает JSON. **Импорт JSON** загружает его в эту или другую браузерную библиотеку после проверки.

Данные хранятся в IndexedDB текущего браузера и адреса. Для переноса и резервной копии используйте JSON; черновик можно отдельно скачать из редактора. Приложение работает без внешних запросов после загрузки.

## Поддерживаемый режим и ограничения

Генератор прототипа создаёт одно связное дерево из 12 или 30 квадратных комнат 2×2 м на площадке 20×20 м. Проёмы 1.4 м, коридоры 0.4 м, расположение ортогональное. Все готовые карты проходят общую физическую проверку и проверку маршрута.

Произвольные формы, отдельные стены и проёмы доступны для ручного редактирования. Автоматическая генерация циклов, использование произвольной площадки, целевое покрытие 65% и ограничения прямого/вынужденного хода 12/20 м в публичный профиль не входят. Маршрут-эталон приблизительный. Большие карты, Android и исследовательский рейтинг сложности отложены. Старый универсальный поиск сохранён в исходниках и скрыт из интерфейса.

## Установка и разработка

Нужны Bun 1.4.4 и Node.js 22. Зависимости закреплены в `bun.lock`.

```sh
bun install --frozen-lockfile
bun run build
./start-web.command  # production-сборка, http://127.0.0.1:1421
```

```sh
bun run dev          # разработка на том же порту
bun run check        # strict TypeScript, ядро без DOM, границы импортов
bun test tests/unit
bun run format:check
bunx playwright install chromium --no-shell  # один раз
bun run test:e2e
```

Перед браузерными тестами остановите открытый сервер: тесты сами занимают порт 1421. Полная функциональная регрессия включает редактор, генератор, запись, восстановление, импорт/экспорт, WebGL и production-сборку. Большая PERF-03 нагрузка M-50/M-100 явно opt-in через `MAZE_LARGE_PERF=1`; её прежний отчёт сохранён.
