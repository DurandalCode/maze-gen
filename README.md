## Разработка

Нужны Bun 1.4.4 и Node.js 22. Зависимости зафиксированы в `bun.lock`.

```sh
bun install --frozen-lockfile
bun run dev       # http://127.0.0.1:1421, без перехода на другой порт
bun run check     # strict TypeScript, ядро без DOM, границы импортов
bun test tests/unit
bun run build
bunx playwright install chromium --no-shell # один раз для браузерных проверок
bun run test:e2e
```

`bun run preview` запускает production-сборку на том же порту. Браузерные тесты сами запускают и останавливают dev-сервер; порт должен быть свободен. Сеть нужна при установке зависимостей и тестового браузера; само приложение внешних ресурсов не загружает.

Главная страница открывает библиотеку. «Создать две комнаты» сохраняет начальный шаблон; затем доступны просмотр и прохождение. Редактор, генератор, файловый обмен и APK ещё не готовы. Результаты интерфейса и WebGL — `reports/ui-runtime.md`. Границы исходников описаны в `src/README.md`; результаты B-01 — в `reports/B-01.md`.
