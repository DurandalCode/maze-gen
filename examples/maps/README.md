# Сохранённые карты

## Одобренный вортексный гибрид09

[`approved-vortex-hybrid09.json`](approved-vortex-hybrid09.json) — **точный экспорт** карты `5acfbf0115ba3765582b24f5`, которую Макс проверил прохождением и пользователь одобрил как хороший лабиринт. Это подтверждение конкретной карты, а не универсального качества генератора.

- 96 настоящих рам, 5 межспиральных дворов, 12 независимых циклов.
- Неизменённый анализ: Л2К2; чистые возвраты без тупиков внутри.
- Заход от внешней развилки внутрь: 10,45 и 10,17 м, по три перехода между реальными витками.
- Явный локальный профиль 8/64 м; крыша и противоположные внешние вход/выход.
- Seed: `vortex-chaotic-05`. Новая генерация не обещает побайтное воспроизведение этого исторического прототипа: некоторые проёмы позднее выбирались иначе. **Этот JSON — самостоятельный эталон**, его нельзя заменять перегенерированной похожей картой.

Экспорт получен из живого API библиотеки1424 и байтно сверен с экспортом исходной сохранённой карты. SHA-256:

`32f8c1fcab136a91cc525558c25f52ba869724f02b6c940cb2f544babebe87a8`

Размер: 137727 байт. Импортируйте JSON обычной кнопкой загрузки карты/библиотеки. В репозитории нет записей прохождения или личной истории игрока. В локальной библиотеке автора исходная ссылка: `http://127.0.0.1:1424/?maze=5acfbf0115ba3765582b24f5&blind=1`; она доступна только на его машине.

## Одобренная короткая концевая петля F11

[`approved-vortex-ending-ring.json`](approved-vortex-ending-ring.json) — точный экспорт одобренной пользователем карты `4d0fb3b9d2c9ae84eb80bb0b` из рабочей библиотеки1428, а не перегенерация её seed. Исторический гибрид09 выше сохранён отдельно.

- 101 настоящая рама; локальная концовка добавляет3 рамы и около22м² проходимого пола.
- Короткий возврат35,8469м **не является формальной К** (порог40м не менялся). Две прежние квалифицированные Л и две чистые глубокие К сохранены.
- Профиль8/64м, крыша, прежние порталы. Единственное локальное геометрическое исключение: добавленный участок выходит на2,98м за прежнюю глобальную опорную плоскость выхода. Сам проём остаётся внешним и свободным; общее правило противоположных крайних портов для генераторов не ослаблено.
- Это последовательность локальных A/B-правок сохранённой карты F11, а не обещание, что обычная кнопка генерации воспроизводит эту концовку. Для точного варианта открывайте этот JSON. F-метки поддерживаются приложением; личных прохождений в репозитории нет.

Размер153042байта, SHA-256:

`3c34868180fb52210fb290a911efe954e8e9eef44f68ec062154d29029be986d`

JSON байтно сверен с экспортом живой библиотеки до публикации. На другой машине откройте файл кнопкой «Открыть», затем при желании сохраните в свою библиотеку. Перенос личных карт/прохождений описан в [инструкцииПК](../../docs/pc-transfer.md).
