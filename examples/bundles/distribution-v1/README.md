# Первый набор для бандла: карты 01–03

Предыдущая версия. Активный набор с пределом 75 модулей находится в
[distribution-v2](../distribution-v2/README.md). Старые карты и ссылки сохранены.

Три кандидата для ручной доработки. В каждой карте включена крыша и после
загрузки JSON подтверждены минимум одна маршрутная ловушка Л и одна кольцевая К.
Кольцо проверяется общим квалификатором `loopTraps`, а не только числом циклов.
Качество прохождения человеком ещё не оценено.

Ссылки используют локальный сервер на порту 1420 и его библиотеку `.local-data`.
На другом ПК импортируйте [bundle.json](bundle.json) через импорт библиотеки.
Одиночную карту можно открыть её JSON через кнопку «Открыть».
Исходные JSON в этой папке сохраняются как контрольные копии; модификации
сохраняйте отдельно в библиотеке или новым файлом.

## Что проверено

- Связность, путь к выходу, точное число запрошенных циклов и состав модулей.
- Обе разновидности ловушек после сериализации и повторной загрузки.
- Каждый открытый переход с коллизиями стен и стоек в обоих направлениях.
- Полное прохождение физическим `Player` от входа до выхода.
- Сохранение контурного рисунка живого типа.
- SHA-256 исходных файлов и импорт общего пакета без личных прохождений.

У классического и живого типов подтверждена скрытость обоих порталов.
**У коридорного скрытость порталов не сертифицирована**: это открытый пункт
доработки, а не пройденная проверка. Вход и выход всех трёх карт находятся
на противоположных внешних сторонах. Расширенный рейтинг сложности не запускался.

## Воспроизведение и проверка

Сохранённые JSON — точные версии для редактирования. Рецепты штатной генерации
для текущего кода:

```powershell
bun scripts/prepare-distribution-map.ts classical BUNDLE-01-CLASSICAL 10 10 test-results/distribution/01.json
$env:MAZE_CYCLES='1'
bun scripts/prepare-distribution-map.ts living BUNDLE-02-LIVING 10 10 test-results/distribution/02.json
bun scripts/prepare-distribution-map.ts corridor BUNDLE-03-CORRIDOR-3 50 30 test-results/distribution/03.json
Remove-Item Env:MAZE_CYCLES
bun scripts/check-distribution-bundle.ts examples/bundles/distribution-v1
bun scripts/import-library.ts --check examples/bundles/distribution-v1/bundle.json
```

Для установки карт в локальную библиотеку при переносе:

```powershell
bun scripts/import-library.ts examples/bundles/distribution-v1/bundle.json
bun run dev
```

Число модулей, контрольные суммы и ID библиотеки находятся в
[manifest.json](manifest.json). После правок генератора сохранённые карты
не заменяются автоматически новым результатом того же seed.
