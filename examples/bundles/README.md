# Бандл лабиринтов

Активная версия: [distribution-v2](distribution-v2/README.md).
В выбранном наборе пять карт: классический, квадратный живой,
органический с дворами, гибридный вортекс и исправленный мостовой.
Верхний предел — 75 физических модулей на карту; фактически 60–75.

В каждой карте обязательны минимум одна маршрутная Л и одна кольцевая К.
Желаемый результат — по две каждого вида; не объявляем его достигнутым,
если общий квалификатор не подтвердил нужное количество. Число циклов
и число кольцевых ловушек проверяются отдельно.

Карты встроены в Windows EXE и автоматически добавляются в библиотеку.
Поставка ZIP также содержит установщик EXE и JSON для переноса.
Коридорный вариант заменён органическим гибридом с дворами.
Остальные пять карт из первоначального плана на десять пока не входят в поставку.

[distribution-v1](distribution-v1/README.md) — прежние карты на 94–100 модулей,
оставленные для сохранности старых ссылок и пользовательских правок.
В активный набор на 75 модулей они не входят.
