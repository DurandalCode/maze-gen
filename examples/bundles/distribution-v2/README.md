# Maze Lab: пять карт для ПК

Выбранный набор для распространения, максимум 75 физических модулей на карту.
В каждой карте крыша, минимум одна обычная ловушка Л и одно настоящее возвратное кольцо К.

| [02 · Живой квадратный](02-living.json) | 64 | 1 / 1 |
| [03 · Органический гибрид с дворами](03-free-hybrid.json) | 70 | 1 / 1 |
| [04 · Гибридный вортекс](04-vortex-hybrid.json) | 75 | 1 / 1 |

## Запуск на Windows 10/11 x64

Распакуйте весь ZIP в отдельную папку и запустите `maze-lab.exe`.
Альтернатива — установить приложение через `Maze-Lab-setup.exe` из той же поставки.
Для отрисовки нужен Microsoft Edge WebView2 Runtime; установщик приложения проверяет его наличие.

Откройте «Библиотека»: пять карт добавляются автоматически при первом запуске.
Рядом с каждой есть кнопка «Пройти вслепую».
Карта целиком открывается отдельной кнопкой «Открыть».
Для ручного импорта или переноса в другую версию выберите «Импортировать записи» и `maps/bundle.json` из распакованной папки.
При использовании установщика карты также лежат в подпапке `maps` каталога установки приложения.

Библиотека и прохождения хранятся локально на устройстве. Для переноса результатов используйте
«Библиотека» → «Экспортировать записи». Распространяемый `bundle.json` содержит только пять карт,
без чужих прохождений и меток. В начале прохождения и на паузе показывается ориентир выхода.

## Свойства и проверка

Классический: raw cold строго ниже 20% на 2048 выборках для всех трёх стратегий:
18,5520%, 19,9095%, 19,0045%. Отчёт привязан к SHA исходного JSON.
Живой — чистый квадрат 8×8. Органический содержит 10 дворов, восемь из них проходные.
Вортекс содержит пять проходных дворов. У мостовой карты два моста с разными ролями;
сила просвечивания ткани — 25% прежнего уровня.

У органического профиль прямого/непрерывного хода 8/64 м (фактически 7/53,78 м),
у вортекса — 8/64 м (фактически 5,28/60,49 м).
Результат проверки скрытости порталов каждой карты записан в `manifest.json` без подмены исходной геометрии.

Проверяются SHA всех выбранных карт, квалификация Л/К, связность, физические переходы в обе стороны,
полное прохождение Player и импорт бандла с сохранением точной геометрии и настроек.
Коридорная карта и прежняя мостовая версия в состав бандла не входят.
Исторические JSON в этой папке сохранены отдельно от состава `manifest.json`.

## Повторная сборка из репозитория

```powershell
bun scripts/package-distribution-bundle.ts
bun scripts/check-distribution-bundle.ts
bun scripts/import-library.ts --check examples/bundles/distribution-v2/bundle.json
powershell -ExecutionPolicy Bypass -File scripts/build-pc-bundle.ps1
```

Выбранные карты фиксируются в `examples/maps/selected-maps.json`; упаковщик отказывается
при изменении их SHA. Для свободных карт используются сохранённые геометрические производные:
рецепты organic/vortex/bridge воспроизводят конкретные карты, а не только seed.
