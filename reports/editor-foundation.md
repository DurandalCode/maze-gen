# Веб-редактор — рабочая приёмка

E-01 реализован: CommandStore хранит до 100 inverse patches, не полные документы; revisions физики/внешнего вида/метаданных и UI-разделены. Undo/redo создают монотонный source revision, но восстанавливают исходные hashes. 1000 локальных preview во время drag не изменяют Document, один mouseup — одна команда. Нормализация/schema failure атомарны, физически некорректный draft доступен; удаление модуля включает его проёмы и ссылающиеся соединения. Snap по умолчанию выключен, при включении 0.1 м / 15°. Core остаётся ES2022 без DOM/React/Three.

E-02/03 UI связан с библиотекой. Доступны Новый проект, редактор saved map и восстановление compact draft summaries. План использует общие declarative contours, устойчивые проёмы, реальную форму круга/треугольника/holes для hit-test. Перемещение/Shift-поворот, pan/zoom, числовые параметры, site contour/holes, line/arc walls, роли/положение/ширина проёмов, явные соединения и удаление/undo. Source contour cache переиспользуется по definition hash/parameters; pointermove рисует только локальный overlay поверх cached base, без compile/navmesh. Blueprint не выдаётся за глобально готовую карту; актуальный 3D доступен после worker validation.

EditorPreparation связывает готовность с физической и визуальной ревизией. Новый physical edit отменяет устаревшую работу, result старого layout не включает Play. Визуальная правка не перезапускает pending physics; готовый navmesh сохраняется тем же объектом. Lightweight identity worker пересчитывает hashes, а при изменении необходимого terrain margin — render buffers; физическая навигация не строится. Метаданные/выделение не submit jobs. Worker identity расположен до prepareWorld; это проверено оракулом на schema-valid/physical-invalid document.

E-04 реализуется как веб-интеграция (Android physical gate пользователь явно отложил). Autosave — один активный write и последний pending Document, debounce350ms, acknowledgement после IDB complete. Ready commit проверяет current physics/visual domains, ожидает autosave и атомарный commit immutable map/project pointer. Optional expectedBaseRevisionHash и draft-content guards не дают перезаписать чужой head/draft. Historical saved map открывается копией. При ошибке работы остаются в редакторе, доступны retry/emergency draft JSON и сохранение отдельной копии. Raw draft serialize/parse работает storage-worker до открытия IndexedDB. Backup не является ready package; отдельный формат maze-reboot-draft v1.

Оракулы: 10 command/plan unit tests, 3 preparation tests, 2 дополнительных repository guards. Четыре Browser editor E2E pass, включая emergency backup/restore и injected QuotaExceededError. Основные сценарии: metadata/roof не создают compile, gesture→one undo, invalid transform→Play disabled→undo→ready commit; invalid circle draft→close/reload→restore→explicit entrance/exit→3D→saved Play с previewed=true. Найдены/исправлены canvas autofocus scroll, сдвиг плана подсказкой и выбор владельца повторного проёма.

PERF-03 pass на Apple M4 Pro, Chromium 141, viewport1440×1000, DPR1. Для каждого F-02/M-50/M-100: 1000 paced DOM PointerEvent moves (4/frame) с реальными pointerdown/up, актуальный canvas редактора, отдельный M-100 compile worker активен до/после. Измерение event.timeStamp→canvas submission в requestAnimationFrame; физическая задержка монитора не измерялась. По всем 1001 input events: p95 9.2 / 9.3 / 9.2 ms, лимит ≤100 ms. Один gesture даёт одну команду. Полные ряды и source hashes: `reports/performance/editor-pointer.json`. Нагрузка fixtures не уменьшалась.

При разделении загрузки Three/Walk/Editor основной JS library entry снизился с ~818 KB до ~279 KB (raw build size); это наблюдение о bundle, не подмена ещё открытого L-1000/PERF-04.

Общая проверка: 123 unit tests pass; build/check pass. Полная браузерная регрессия: 20/20 pass (25.1s), включая built production-origin, WebGL lifecycle, обмен и запись. Генератор и остальные PC performance gates пока не готовы. Android устройство пользователь проверит сам; не считать его отсутствие физическим pass и не блокировать доступную веб-работу.
