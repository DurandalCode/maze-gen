# JSON-обмен — 2026-11-11

IO-01/02/03 реализованы для браузера. Пакет `maze-reboot-package` v1 содержит definitions/maps/projects/sessions/chunks и manifest с counts/entityHashes. Размер 32 MiB проверяется по размеру File до чтения и по UTF-8 до JSON.parse; лимиты массивов проверяются до нормализации. Проверяются declarative builders, definition/revision/chunk/condition hashes, версии, неизвестные поля, зависимости, полная sequence, итоговые elapsed/distance/lastSample и условия ввода/окружения. Старые форматы отклоняются. Необязательное project.originId сохраняет происхождение импортированной копии.

File читается/разбирается storage-worker. Schema-valid сущности помещаются только в невидимый importStaging. Карты последовательно проходят compute-worker validate; результат связывается с revision/world/nav hashes и версиями, не с ready-флагом из JSON. UI получает небольшие counts/conflicts; полные JSON-тексты не создаются в React. Карта на проверку читается отдельно с её definitions, без загрузки chunks всего пакета. После проверки доступны явные «Применить» и «Отменить».

Commit атомарно пишет definitions/maps/projects/summaries/sessions/chunks и удаляет только свой staging. Hashing, подготовка summary и перехеширование скопированных chunks закончены до write transaction. Optimistic guards отклоняют изменения библиотеки между подготовкой и записью. Duplicate immutable hash не затирает запись; повреждённое существующее definition/map не принимается как duplicate. Конфликт проекта добавляет копию с originId; повтор идентичной копии не размножает проекты, изменённая пользователем копия сохраняется. Конфликт попытки требует явного выбора новых копий; originId и новая sequence/body hashes согласованы. Старые проекты/попытки не заменяются.

Отмена import отличается от compute terminate. JobManager отправляет cooperative cancel и ждёт abort/complete. До complete IDB transaction abort оставляет библиотеку прежней. Complete, выигравший гонку, возвращает «импорт завершён» даже при позднем cancel. При потере worker результат обозначен как неизвестный и библиотека перечитывается; ложное cancelled после возможного коммита не выдаётся. Запуск очищает orphan staging без удаления рабочих данных.

Экспорт читает только выбранные объекты и полные зависимости, chunks последовательно. Encoded entities/hash fragments создаются один раз; пакеты формируются с точным UTF-8 размером. Каждый пакет содержит полную карту/definitions/condition/историю выбранной попытки и собственный manifest. Отдельная попытка не разрезается между пакетами; ITEM_TOO_LARGE не создаёт усечённого файла. Изменившаяся во время чтения попытка даёт EXPORT_CHANGED. При разбиении повторяются необходимые зависимости.

Storage-worker отдаёт по одному Blob до 32 MiB и держит только текущий pack/следующий item; React не сериализует JSON. UI предлагает файл и подготавливает следующий после действия пользователя, освобождает предыдущий objectURL. Показывает номер/количество подготовленных пакетов и сколько отправлено на скачивание; запись файла на диск браузера не выдаётся за подтверждённую приложением. Закрытие очищает iterator/URL. Android bridge/sharesheet — отдельная APK-02.

Проверки: build/strict check, 107 unit tests всего (10 exchange, включая смешанный F-02 без установленного каталога, подделку hashes, лимиты, дубликаты, project/session conflicts, quota rollback, abort до/внутри/после transaction, полный session export, независимое повторное импортирование каждого split-пакета), 13 Browser E2E. Три E2E обмена используют настоящий File→storage worker→compute-worker→commit; cancel/reimport/legacy/invalid geometry; Blob download→отдельная browser context/library→preview. Разбиение проверено с меньшим тестовым лимитом при неизменном production 32 MiB; огромный реальный пакет и Android остаются в общих стресс/мобильных gates.

Открыто: физический ПК→APK→ПК oracle, Android chunk bridge и sharesheet, нагрузочные замеры максимального пакета, cancel latency на каждом тяжёлом этапе. IO-01/02/03 отмечены как функционально выполненные на ПК; QA-01/02 и APK gates ещё не pass. Не объявлять весь выпуск готовым.
