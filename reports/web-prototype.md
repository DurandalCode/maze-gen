# Веб-прототип

Пользователь 2026-11-11 заменил полное закрытие SDD на рабочий веб-цикл. Актуальный объём: `docs/reboot/WEB-PROTOTYPE.md`.

## Поставляемое поведение

Публичный генератор `prototype-grid-v1`: 12 или 30 комнат 2×2 м, площадка 20×20 м, ортогональная сетка, случайное связное дерево. Проёмы 1.4 м, коридоры 0.4 м. Seed и версия определяют результат; requestId не меняет геометрию. Непроверенная карта не публикуется как готовая. Физика и навигация общие с редактором и прохождением. Поиск работает в отдельном worker; отмена не меняет существующие карты и черновики.

Готовый результат открывается отдельным проектом. Редактор поддерживает существующие формы/стены/проёмы, undo/redo и черновики. Перед прохождением сохраняется актуальная проверенная ревизия. Сохранённые карты, попытки и seed/параметры генерации переживают перезагрузку; JSON переносит карту вместе с зависимостями, происхождением и выбранной попыткой. Уже просмотренные карты показывают свои названия в библиотеке.

Универсальный frontier-поиск сохранён в исходниках, но скрыт из публичного интерфейса. Его прежние большие цели не являются критериями поставки. Никаких дополнительных архитектурных переработок после смены цели не начиналось; добавлен отдельный ограниченный профиль из-за конкретного блокера стабильности общего поиска.

## Проверки

- Build/check passed: strict TypeScript, core без DOM, AST-границы импортов, production Vite build.
- 143 unit tests passed. Профиль проверен на пяти фиксированных seed для каждого размера; точное число комнат/соединений, одна компонента, ноль циклов, воспроизводимость, manifest. Маршрут пройден реальным swept MovementController до выхода.
- Целевой Browser E2E passed: создать исходный черновик → сгенерировать → изменить положение комнаты → проверить → пройти с реальным keyboard movement → остановить/сохранить попытку → reload → повторно открыть геометрию → экспорт попытки → импорт в чистый browser context → открыть карту. Исходный черновик сохранён. Это тест сохранения остановленной попытки; достижение выхода отдельно проверено MovementController.
- Реальный generation worker в Chromium даёт те же revision/nav hashes, что Bun, для среднего профиля. Отмена возвращает в исходную библиотеку без добавления карты.
- Полная функциональная Browser регрессия: 21 passed, 1 явно skipped (25.3s). Повторный прогон после уточнения двух selectors модального просмотра полностью зелёный. Большая PERF-03 M-50/M-100 явно пропускается по новому объёму, доступна через MAZE_LARGE_PERF=1; прежний отчёт сохранён.

В ходе предыдущей универсальной реализации найдены и исправлены два численных отказа kernel: sub-tolerance consecutive offset vertices и area invariant без учёта grid rounding на повёрнутом пересечении. Сохранены точные regression inputs; независимые проверки площади/сохранения компоненты/дистанций проходят. Публичные геометрические допуски и физические размеры не изменены.

## Известные ограничения

Автогенерация поддерживает один профиль и один результат за запуск. Произвольная площадка, автоматические циклы/смешанные формы, цель покрытия 65% и ограничения 12/20 м не обещаются. Ручное редактирование может сделать карту некорректной — ошибки показываются, Play блокируется до исправления. Маршрут-эталон приблизительный.

Данные локальны для браузера и origin; резервная копия и перенос — JSON. Основной сценарий предназначен для ПК. Android, AN-01…06, L-1000/W-60/M-100 и большие VIS/PERF отложены пользователем.

## Запуск

`./start-web.command` запускает собранный production frontend на `http://127.0.0.1:1421`. Для пересборки: `bun run build`. Инструкция пользовательского цикла — README.md.

Production-сборка открыта в браузере Codex, видна библиотека и кнопка «Создать лабиринт». Сервер оставлен на порту 1421 через start-web.command. Форматирование и git diff --check проходят. Полный SDD не объявляется закрытым; текущая поставка завершает только согласованный веб-прототип.
