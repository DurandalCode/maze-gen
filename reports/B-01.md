# B-01 — новый каркас

Статус: выполнено. Дата: 2026-11-11. Ветка: `reboot/sdd-clean-start`.

## Результат

Созданы новые package.json/bun.lock, strict TypeScript, Vite, React entrypoint, стартовая страница и команды dev/build/check/test/test:e2e. Dev и preview используют `http://127.0.0.1:1421` с strictPort. Three.js зафиксирован для последующих задач, в стартовую страницу не импортируется.

Ядро компилируется с `lib: ES2022`, `types: []`, без DOM. Проверка AST запрещает ядру зависимости на UI/renderer/platform/jobs/repository и внешние пакеты; geometry/kernel допускает только выбранные геометрические адаптеры. Проверяются статические импорты, реэкспорты, import types и динамические импорты. Вычисляемые пути отклоняются. Каталоги legacy и сохранённых сборочных артефактов запрещены для всех модулей.

Сохранённые `.tools`, Android build assets и прежний dist не использовались как исходники. Новая сборка заменяет содержимое dist. Старые локальные Android-файлы остались вне Git и не включены в изменения.
