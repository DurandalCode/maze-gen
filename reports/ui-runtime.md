# Библиотека, прохождение и WebGL — 2026-11-11

Новый интерфейс заменил bootstrap. Библиотека отдельно загружает summaries карт и попыток, поддерживает поиск/сортировку/статус, страницы по 30, retry, переименование, удаление с перечислением последствий. Загрузка выбранной карты отменяется отдельно; её прогресс не блокирует поиск и вкладки. Карточки до явного просмотра используют нейтральное название. Кнопка «Создать две комнаты» создаёт явный начальный шаблон, не подменяет процедурный генератор.

Просмотр использует PlanRenderer/WorldScene из подготовленного compute-worker snapshot. Явный просмотр запоминается на устройстве по immutable revision и сохраняется в condition последующих попыток. Слепой старт не создаёт план/миниатюру и не показывает название. Скорость и режим ввода фиксируются до записи session header; движение начинается только после подтверждённого перехода running.

Клавиатура/мышь и сенсорные кнопки используют один MovementController. Запись идёт через Recorder/storage-worker; пауза/blur/background/context-loss прекращают движение синхронно. Перезапуск восстанавливает последнюю подтверждённую позу/sequence; UI сообщает о возможном неподтверждённом интервале. Остановка ждёт последнего chunk и terminal commit, результат остаётся доступен в библиотеке. Есть явные saving/saved/error/retry; очередь записи не привязана к загрузчикам списка.

Исправлены обнаруженные сквозной проверкой дефекты: prepared/interrupted не переводятся в недопустимый paused при закрытии; lifecycle pause выигрывает гонку с pending start; одинаковая нормализация времён event/sample/chunk устраняет ошибку на 550.0000000000001 ms; физические подшаги прекращаются сразу при паузе/финише. Контактные повороты записываются отдельными событиями. Камера согласована со знаком yaw физического движения.

Реальная потеря WebGL выявила проблему lazy acquisition расширения восстановления: после loss получить WEBGL_lose_context уже нельзя. Handle сохраняется заранее, восстановление перестраивает тени. Проверены resize, lost/restored, пауза/сохранение/продолжение той же попытки. За 20 реальных циклов GPU geometries/textures каждый раз возвращаются к нулю. Отчёт: `reports/visual/lifecycle/pc-20-cycles.json`; ratio медианы последних/первых пяти JS heap после CDP GC 1.0753 (<1.10), ряд не монотонный.

Проверки: 99 unit tests, strict check/build, 10 Browser E2E. Три сценария нового UI: слепой ход→commit→reload→recovery→stop→result, preview→blind→touch, context-loss→restore→blur без новой попытки. Нет внешних запросов, viewport 390/360 px без горизонтального переполнения. Отдельный oracle подтверждает отсутствие треугольников над отверстием в полу, обеих сторонах 6mm roof slab и terrain.

Восемь фиксированных видов сняты с 120 warmup frames, сохранены в `reports/visual/candidate-pc-2026-11-11/` с manifest OS/CPU/GPU/backend/разрешения/hashes. Изображения просмотрены: каркас/укосины/крепёж, чёрная и цветная ткань, поры вблизи, непрозрачный control, крыша, четыре формы, лес присутствуют. Это первая кандидатная база, старое pixel-equivalence не заявляется. Полный VIS+PERF gate ещё открыт: нет сравнительных динамических pixel-diff, 10-минутного M-50 benchmark и физического Android. R-01/R-03 не объявлены принятыми только по скриншотам.

UX-01/02 функционально реализованы; общие приёмочные задачи остаются в работе до L-1000/PERF и зависимых gates. REC-03/R-02 реализованы и проверены в браузере; APK lifecycle остаётся в APK-02/03. Файловый обмен, редактор, генератор, APK и исследовательские задачи продолжаются отдельно.

Начат IO-01: строгий package parser проверяет 32 MiB UTF-8 до JSON.parse, лимиты до нормализации, definition/revision/chunk/condition и manifest hashes, полные зависимости и непрерывную историю. Смешанные формы переносятся без установленного каталога. Это пока API/тесты: atomic staging/commit, конфликты, export splitting и UI ещё не готовы.
