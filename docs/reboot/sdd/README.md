## Зафиксированный объём

Свободная геометрия и расширяемый каталог, включая круг/треугольник с первого ядра. Один этаж; полный существующий внешний вид. ПК: редактор и генерация; Android APK: просмотр/прохождение/библиотека. Цель 50×50 м, ориентир 100×100 м. JSON-обмен без миграции старых данных. Основной режим генератора использует площадку, 3 варианта и ожидание до 60 секунд — подтверждено пользователем.

Старые отслеживаемые исходники удалены по решению пользователя. Файлы вне Git оставлены по его отдельному выбору и не включаются в новую реализацию. Git сохраняет старую версию `ccd19ff`; предварительное снятие старых эталонов не требуется.

Базовые решения: TypeScript/React/Vite/Three.js, новое приложение в корне репозитория, compute/storage workers, IndexedDB summaries/chunks, Java/WebView APK. Дополнительный режим бюджета модулей, начальный профиль physical-v1, 65% мягкой цели покрытия, tree/cyclic и free/orthogonal — инженерные defaults, не отдельные обещания научной сложности.

## Проверка готовности документации

- Входы/выходы, идентичность, версии и пределы формата определены.
- Проёмы и соединения работают с произвольным контуром, контрольные формы входят в первое ядро.
- Есть отмена, bounded queues, stale-result защита и статусы частичного поиска.
- Хранение, lifecycle и конфликты JSON имеют определённые исходы; список не читает полные траектории.
- Каждая задача имеет результат, зависимости и проверку; граф проверяется на неизвестные ID и циклы.
- Исследовательская валидация и мосты не блокируют первый рабочий выпуск.
- Никакие FPS, скриншоты или тесты нового приложения не заявлены пройденными.

Начинать с **B-01**, затем B-02/G-01. Дальнейших продуктовых ответов для этого не требуется.

## Риски, которые проверяются реализацией

Численная устойчивость kernel — G-03; межплатформенные hashes — G-01/GN-04; полный вид при требуемой скорости — R-03/APK-03; размещение смешанных форм в 60 секунд — GN-06. Это явные ограниченные проверки с критериями выхода, а не неопределённые задачи «сделать хорошо».

Нужен физический Android для мобильного gate и позднее люди для AN-05. Пока они недоступны, соответствующие проверки остаются not-run; независимые задачи продолжаются. Release-ключ подписи нужен для производственной поставки, debug APK позволяет начать проверки без него.
