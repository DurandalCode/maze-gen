# Текущая цель: рабочий веб-прототип

Обновлено по прямому указанию пользователя 2026-11-11. Этот объём заменяет прежнюю цель полного закрытия SDD. Исторические SDD-требования и работающий код сохраняются; их открытые пункты не блокируют эту поставку.

Финиш: запускаемая веб-версия с основным сценарием **сгенерировать → поправить в редакторе → пройти → сохранить → загрузить**, инструкцией запуска и короткими известными ограничениями.

## Чек-лист поставки

- [x] Один надёжный профиль генерации небольших/средних карт; поддерживаемые размеры и ограничения видны в UI.
- [x] Генерация выполняется в worker, отмена/ошибка сохраняет исходный проект; готовность подтверждается физической геометрией и навигацией.
- [x] Редактор: локальные изменения, undo/redo, invalid draft, актуальная проверка перед Play.
- [x] Черновики, сохранённые ревизии, перезагрузка и JSON-обмен уже работают; изменения профиля не должны нарушить их.
- [x] Проверить изменённую логику и один браузерный сценарий полного цикла, включая сохранение записи и повторную загрузку.
- [x] Перед поставкой: build/check/unit и полная существующая Browser E2E регрессия.
- [x] Оставить доступный локальный веб-сервер и короткую инструкцию для пробы.
- [x] Общая JSON-библиотека карт и прохождений между браузерами; сохранение после записи на диск.
- [x] Отдельная карточка: план/3D, геометрия, материалы, происхождение, история, прямая ссылка и запуск/продолжение в один клик.

## Решение для стабильного генератора

Для этой поставки: квадратные комнаты 2×2 м на компактной ортогональной сетке, 12 или 30 комнат, случайное воспроизводимое связное дерево, проходы 1.4 м и коридоры 0.4 м. Один вариант за запуск. Полная физическая проверка обязательна. Seed сохраняется с результатом. Это отдельная версия генератора; прежний универсальный frontier-поиск сохраняется в исходниках и не является публичным режимом прототипа.

Генератор создаёт новую площадку 20×20 м и отдельный проект. Произвольные формы, стены, проёмы и размеры можно править существующим редактором. Цель покрытия 65%, лимиты хода 12/20 м и циклическая генерация не входят в обещания этого профиля.

## Явно отложено

Android/APK-приёмка, AN-01…06, L-1000/W-60/M-100 и большие VIS/PERF; дальнейшее расширение каталога/режимов генерации. Никаких новых архитектурных переработок без конкретного блокера основного сценария, геометрии или сохранности данных.

Приёмка завершена: build/check/format, 145 unit tests, полная Browser E2E регрессия и 2 проверки общей библиотеки; 1 большая PERF-проверка явно deferred. Отчёт: [web-prototype.md](../../reports/web-prototype.md). Dev frontend с общей JSON-библиотекой запускается на http://127.0.0.1:1421.
