# Межспиральные дворы вортекса

Явный модификатор `freeVortexHybrid:true` / `hybridVortexParameters` работает
поверх непрерывного хаотичного пресета07. В настройках и редакторе это
«Межспиральные дворы · гибрид». Генерация остаётся обычной seeded-генерацией;
сохранённая карта не используется как каркас следующего запуска.

Для первого проверенного варианта: seed `vortex-chaotic-05`, площадка70×70,
проход2м, четыре базовые спирали96 позиций, исходный непрерывный профиль
после вырезания72 рамы, минимумыЛ2/К2. Только этот явно выбранный профиль
использует пределы прямого/непрерывного пути8/60м. При выходе из непрерывного
пресета возвращается обычный предел16м; глобальные правила не ослаблены.

## Конструкция

Отрицательное пространство учитывается по действительной оболочке пола,
а не по площади всей площадки. Две закрытые полости54.70/36.21м² принадлежат
чистым возвратнымК. Они исключены: внутриК нельзя добавлять двери, тупики,
перекрёстки или другие соединения с основным лабиринтом.

В трёх остальных крупных неправильных бухтах217.55/254.89/496.61м²:

- Детерминированный конечный поиск размещает настоящие2×2/2×6 рамы с
  индивидуальными поворотами. Новые стволовые пролёты максимизированы до3м.
- Близкие реальные грани замыкают компактные дворы. Более короткий замыкающий
  пролёт возможен только между фиксированными существующими креплениями и
  получает явную геометрическую причину в `spanAudit`.
- Неправильные дворы не превышают24м² и открываются двумя выборочными дверями
  в уже существующих стенах. Коридор превращается в отдельную навигационную
  комнату только для нового пролёта, если нужна дверь в его боковине.
- Исходные72 рамы и их соединения сохраняют координаты, повороты, проёмы иIDs.
  Новые связи не обходят защищённые развилки; компонентыЛ остаются деревьями,
  а все внутренние комнатыК — с двумя выходами и без тупиков.

Новых самостоятельных перегородок, BSP, скрытых рам, отдельных несущих стоек
или метровых экранов посреди коридора нет. Каждая панель и стойка проходит
`auditModuleWalls`: её корень — настоящая рама либо пролёт между двумя рамами.
Пролёты исходной композиции не сокращаются для увеличения плотности.

## Проверенный вариант08

100 рам:72 исходные+28 новых. Семь неправильных дворов распределены3/3/1
по трём бухтам. Доступным стало400.36м² отрицательного пространства:
107.83/143.35/149.18м² по секторам. Это41.3% от969.06м² пригодных исходных
бухт.568.70м² пока остались неиспользованными; ещё163.72м² относятся к
сохранённымК, внешним выемкам и малым остаткам и учитываются отдельно.

Остаток не объявляется конструктивно невозможным: поиск ограничен18 новыми
рамами на бухту,16 полными кандидатами на шаг, детерминированным бюджетом
модульных замыканий и96 физическими проверками дверей на бухту. Ledger
содержит площади и причины отказов для всех исходных областей. Это не
процент «заполнения участка» и не оценка человеческой сложности.

Неизменённые квалификаторы подтверждаютЛ2/К2. Реальные длины5.00/51.33м;
1246 капсульных отрезков иPlayer через обаЛ, обаК, все7 дворов и финиш прошли.
ЧистыеК сохранили исходные непрерывные извилистые трассы. Эффект ориентации
и привлекательность новых частей требуют игрового отзыва.

Подготовка: `bun scripts/prepare-vortex-hybrid.ts`.
Публикация в отдельную локальную библиотеку: `bun scripts/publish-vortex-hybrid.ts`.
Browser: `MAZE_GEOMETRY_ID=... bun scripts/vortex-hybrid-browser-check.ts`.
Проверенные артефакты находятся в `outputs/vortex-hybrid-08*` вне репозитория.
Полный набор тестов репозитория для этого игрового прототипа не запускался.

## Отклик анализа

Геометрический адаптер видимости один раз индексирует комнаты и пролёты
в мировых координатах. Проверки pointIn, порядок при совпадении границ,
дыры и поведение мостов сохранены. На карте08 полный диагностический JSON
Л/К побайтно совпал со старой реализацией:24.42с→0.405с на той же машине.
В браузере первый overlayЛ1/Л2/К1/К2 открылся за0.233с. Это измерение
конкретной карты; оно не является гарантией времени для любого размера.

Вспомогательные CLI по умолчанию пишут в `test-results`. Путь можно задать
через `VORTEX_HYBRID_FILE` и `VORTEX_OUTPUT_DIR`; скрипт браузера также читает
`VORTEX_EXPECTED_FILE`. Порт отдельного сервера: `PORT=1424 bun server/index.ts`.
