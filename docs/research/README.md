# Исследовательская база Maze Lab

Дата среза: 2026-11-10. Статус: **рабочие гипотезы и спецификация экспериментов**, не доказанная теория «самого сложного лабиринта».

## Цель

Проектировать **полноразмерные лабиринты для людей**, которые трудно пройти даже при хорошем чувстве направления, без дверей с управлением, подвижных стен и обязательных игровых механик. Допустимы изолированные острова стен, многоуровневые **крытые** переходы и разные конфигурации коридоров. Участник должен иметь физически доступный и безопасный маршрут к цели.

Не смешивать:
1. **Топологическую сложность** — достижимость, компоненты, независимые циклы и границы, двумерные/двухуровневые связи.
2. **Навигационную сложность** — видимая информация, неопределённость выбора, запоминание, чувство направления.
3. **Экспериментально измеренную сложность** — реальный путь, ошибки, повторы и субъективная дезориентация людей.
4. **Строительную осуществимость** — модули, пролёты, ширины проходов, безопасность мостов.

## Зафиксированные уроки

- Человек с хорошим чувством направления может игнорировать «ложные циклы». Число циклов — не самоцель.
- Видимый короткий тупик не создаёт полезной сложности: его можно распознать, не заходя.
- Двусторонний мост не является односторонней ловушкой: посетитель может обнаружить любой его конец первым.
- Крытый мост скрывает обзор сверху, но не скрывает сам факт прохода под ним; «иди под мостом» — тестируемая эвристика, а не предполагаемая ошибка каждого посетителя.
- Из предыдущих записей следует, что некоторые версии симулятора **существенно переоценивали** пройденное расстояние; оценка модели без калибровки — гипотеза.
- В существующих правилах есть ограничения 12 м по прямой и 20 м без выбора. Это настройки конкретных экспериментов пользователя, **не универсальные нормы человеческого восприятия**.

## Порядок работ при перезапуске

1. Сначала единая геометрия и детерминированный навигационный граф; полы, проёмы, лестницы и мосты должны совпадать между 2D-планом, 3D и анализом.
2. Затем тесты достижимости, физической проходимости и стратегии левой/правой руки.
3. Затем простые воспроизводимые агенты: случайный поиск, поиск по памяти, ориентация на цель, направление/контур, «под мостом».
4. После этого — параметризованная исследовательская модель, телеметрия слепых прохождений и подгонка параметров на обучающих данных.
5. Лишь затем — автоматическая оптимизация по метрикам и проверки на новых людях/картах.

При изменении моделей сохранять старые записи и старую версию расчётов; новые результаты не выдавать за сопоставимые без повторного пересчёта на одном наборе карт.
