# Границы модулей

- Чистое ядро: `domain`, `catalog`, `geometry`, `navigation`, `generation`, `observation`, `analysis`, `session`. Только ES2022, без DOM, React, Three.js и адаптеров платформы.
- `geometry/kernel` — единственная точка доступа ядра к clipper2-ts и earcut; зависимости изолированы в G-03.
- Адаптеры: `jobs` (worker orchestration), `repository`, `platform`, `renderer`.
- `ui` — React и композиция приложения. Вычисления и хранение подключаются через адаптеры по последующим задачам.

Пустые области создаются вместе с первой реализацией соответствующей задачи. Сейчас `domain/index.ts` — точка входа будущих контрактов G-01, без фиктивных моделей.

`bun run check` проверяет типы приложения, отдельно компилирует ядро без DOM и проверяет импорты во всех исходниках. Ядро может импортировать только другие области ядра; любые зависимости на адаптеры запрещены, в том числе транзитивно. Старые `src/core`, `legacy`, `.tools`, `dist`, `work`, `android` не используются как исходники веб-приложения. Сохранённые артефакты не удаляются этой конфигурацией; `dist` полностью заменяется новой сборкой.
